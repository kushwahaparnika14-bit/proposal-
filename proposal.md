## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

My project will be a Python program that analyzes login activity to help identify possible security threats. Users will be able to select a CSV file containing login information, including timestamps, usernames, IP addresses, and login statuses. The program will read the file and look for patterns such as repeated failed login attempts from the same IP address. It will also count successful and failed logins and display a summary of the results.

I plan to create a simple graphical user interface using Tkinter so users can interact with the program without having to type commands. The interface will include buttons to open a log file and export a report. The report will contain information about suspicious IP addresses and login activity. The program will be executed by running the Python file, which will open the application window.

I will mainly use Python, CSV files, Tkinter, and GitHub for this project.
